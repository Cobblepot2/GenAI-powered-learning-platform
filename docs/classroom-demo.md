# 第 8/9 周课堂演示清单

安排约 **5 分钟准备、6 分钟讨论**。口头讲述与现场问题记录使用 [讨论脚本](meeting-script.md)；两页摘要为 [进度摘要 PDF](../output/pdf/learnloop-week8-9-progress.pdf)。

## 课前准备（约 5 分钟）

- 将演示包完整解压到一个文件夹，再从解压后的目录启动；不要在压缩包内运行。
- Windows 双击根目录的 `Start-Demo.cmd`；也可在该目录打开终端，运行 `python serve.py`。运行原型兼容 **Python 3.7+**，无需 Node、第三方 Python 库、模型密钥或联网。浏览器访问 `http://127.0.0.1:5241`，不要双击 HTML 文件。
- 若端口被占用，运行 `python serve.py --port 5242`，访问 `http://127.0.0.1:5242`。启动终端在演示时保持打开；结束后可按 `Ctrl+C` 停止服务。
- 使用固定浏览器配置与地址排练一次。自建课程、草稿、进度和事件保存在该浏览器的 `localStorage` 中；同一浏览器配置、同一来源与端口才能沿用数据。换浏览器或配置、改端口，或将 `127.0.0.1` 换成 `localhost`，都会使用独立数据。
- **不要清理已有数据，也不要点击“重置本地演示数据”。** 如需从空白状态演示，使用新的浏览器配置或不同端口；不要覆盖已有草稿。先查看当前草稿，可直接使用它展示编辑流程。
- 确认三门内置课可打开：“把模糊需求变成用户故事”“与 AI 编程代理有效协作”“在团队里做出有依据的产品决定”。准备好教师草稿，提前补充并核对主题内容、案例及配套题，控制现场编辑时间。
- 打开 PDF 与 [课程库截图](screenshots/course-library.jpg) 备用。排练和 QA 产生的事件只能作为操作记录，不能作为真实用户反馈。

## 必须说清的能力边界

- 当前草稿来自固定规则模板，没有调用真实生成式 AI，也不检索主题事实；不应把模板内容说成 AI 推理结果。
- 教师可编辑课程标题、简介、章节标题、正文与思考题；配套情境选择题、选项、正确答案和解释目前只读。发布后的修改需再次发布才会更新课程库。
- 学习者与教师是演示视图，没有登录、权限或多人共享。思考题供自主练习，不收集书面答案。
- 当前没有可报告的真实用户访谈或测试结果；[用户验证文档](user-validation.md) 是待执行方案。

## 启动失败时

已安装 Python 的电脑断网后仍可运行本地原型。若无法启动或浏览器打不开，改用已解压的两页 PDF 和课程库截图讲解设计、范围与计划，并记下故障现象。**截图只能展示界面，不能证明答题、保存或发布交互已成功。**
